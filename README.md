# NIFTY-50 Market Data: Foundation for ETL and Power BI Analysis

## 📌 Project Overview
This project focuses on the analysis of 22 years of historical stock data from the NIFTY-50 index (2002–2024). The objective is to build robust ETL (Extract, Transform, Load) pipelines, design interactive Power BI dashboards, conduct algorithmic research, and develop machine learning predictive models to uncover actionable market trends.

## 📊 Dataset Details
* **Total Records:** 238,485
* **Data Span:** 2002–2024 (22 Years)
* **Companies:** 50+
* **Key Columns:** 8 raw columns including Date (trading day timestamp), Open, High, Low, Close (Primary Metric), and Volume.
